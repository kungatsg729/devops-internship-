# One Month Report

Today marks the end of our first month at the internship program in DevOps provided by Codavatar.

So far, the content provided covers:

- Linux and scripting
- Using version control systems
- Creating CI/CD pipelines
- Creating a containerization environment
- Launching SQL or NoSQL databases in those environments

Everything is going very smoothly and we are getting more and more comfortable with the tools used in DevOps. Furthermore, we have also explored contents of higher weeks utilizing our extra time.

We did experience a lot of hurdles, but we went through all of them and came out even stronger. We searched the net, asked for help from colleagues, and used other resources to find answers or debug certain programs. It was extremely hectic running into problems, but finding a solution always felt worth the trouble.

## Working Environment

The working environment is very peaceful, with good infrastructure and great co-workers. We have all gotten along very well and even try to learn a thing or two from each other's courses. We believe no knowledge is unnecessary knowledge.

Everyone works very diligently, and there is just an amazing working condition here.

## Overall Experience

Overall, the experience so far has been marvelous, and I hope the same continues.

Looking at the course, I see that Terraform and Ansible are left out, which are major requirements for DevOps or cloud-related jobs today. I feel like those would be good additions to the program. However, I've also been self-learning those topics to bridge the gap between an internship program and an actual job.

## Conclusion

To conclude, we have come a long way from where we were a month ago. From not knowing much about what DevOps even is to being able to build our own CI/CD pipelines and containerized environments, run applications in them, and maneuver through servers using Linux commands, we have been able to see definitive improvements.
